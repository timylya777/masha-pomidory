## Это не вирус и не фишинг 🙂

Если ссылку скинули в чат и страшно открывать — вот честная разборка:

- **Это обычная статическая страница.** Весь сайт — один файл `index.html` + одна картинка `img/rozysk.jpg`. Никакого сервера, баз данных и личных кабинетов.
- **Ничего никуда не отправляется.** Нет форм с паролями, нет карт, нет «войдите через Google». Кнопка «Оформить» просто открывает ссылку `t.me/rramfff` с готовым текстом заказа — дальше вы сами решаете, отправлять или нет.
- **Нет трекеров и рекламы.** Страница не грузит ничего извне: ни шрифтов, ни скриптов, ни счётчиков. Можно открыть с выключенным интернетом после первой загрузки.
- **Как проверить за 10 секунд:** откройте исходный код страницы (в браузере: меню → «Исходный код») — там один читаемый HTML, всё на виду. Или смотрите этот репозиторий: тут лежат ровно те же файлы, что отдаёт сайт.
